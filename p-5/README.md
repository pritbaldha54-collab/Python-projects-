# Employee Management System

A simple **Python OOP project** for managing different types of employees. The program allows users to create and display details of an Employee, Manager, and Developer using a menu-driven system.

## Features

- Create an Employee
- Create a Manager with department details
- Create a Developer with programming language details
- Display saved employee details
- Uses OOP concepts such as:
  - Classes and Objects
  - Encapsulation
  - Inheritance
  - Method Overriding
  - `super()`
  - Destructor

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```
