## 🌟 Project Overview

This project explores sales performance using an Excel workbook. It brings together transaction-level data, descriptive statistics, a linear regression summary, pivot-table analysis, and a visual dashboard to help understand business performance.

## 🎯 Project Objectives

- Track total sales, profit, quantity sold, customer count, and profit margin.
- Compare sales across product categories and regions.
- Review sales and profit using descriptive statistics.
- Explore the relationship between variables with a linear regression summary.
- Present key metrics in a single dashboard for quick interpretation.

## 📁 Workbook Structure

| Worksheet | Purpose |
|---|---|
| `Data` | Customer and transaction-level records, including region, product category, sales, quantity, discount, order date, and profit. |
| `Linear Regression` | Regression statistics and ANOVA output for a basic relationship analysis. |
| `Descriptive Statistics` | Summary measures for sales and profit, such as mean, median, standard deviation, and skewness. |
| `Pivot Table` | Sales summaries by product category, region, and year. |
| `Dashboard` | High-level KPIs and business-performance visualizations. |

## 🚀 How to Use

1. Open `Project-2.xlsx` in Microsoft Excel or a compatible spreadsheet application.
2. Start with the `Dashboard` sheet for a quick overview.
3. Use `Data` to inspect individual records.
4. Review `Pivot Table` to compare categories, regions, and years.
5. Check `Descriptive Statistics` and `Linear Regression` for statistical summaries.
6. If the source data changes, refresh relevant pivot tables and verify that dashboard formulas and analysis outputs are updated.

## ⚠️ Notes & Limitations

- Dashboard and analysis results depend on the data and formulas saved in the workbook.
- Correlation or regression results do not, by themselves, prove causation.
- Check for missing values, duplicate records, inconsistent categories, and formula errors before using the analysis for business decisions.
- Currency is not specified in the source description; the numeric KPI values are therefore shown without a currency symbol.
