# 📊 Data Analyzer & Transformer Program

A simple Python console-based application that allows users to analyze
and transform numerical datasets. This project demonstrates Python
concepts including functions, recursion, lambda expressions, sorting,
`*args`, `**kwargs`, built-in functions, and function documentation.

------------------------------------------------------------------------

## ✨ Features

-   📥 Input dataset
-   📈 Display data summary
-   🔢 Calculate factorial using recursion
-   🔍 Filter data using Lambda function
-   ↕️ Sort data (Ascending / Descending)
-   🎯 Display unique values
-   📊 Display dataset statistics
-   ⭐ Demonstrate `*args`
-   ⭐ Demonstrate `**kwargs`
-   📖 Display function documentation
-   🚪 Exit program

------------------------------------------------------------------------

## 🛠 Technologies Used

-   Python 3.x
-   Built-in Functions
-   Recursion
-   Lambda Function
-   List Operations
-   Match-Case Statement

------------------------------------------------------------------------
