## 🌟 Project Overview

**Retail Sales Analysis** is a Python-based data analysis project that combines a simple **Retail Sales Management System** with **Exploratory Data Analysis (EDA)**.

The project works with retail transaction data to manage sales records, calculate revenue, examine product and category performance, and visualize important relationships within the dataset.

> 💡 **Goal:** Transform raw retail transactions into clear, useful business insights.

---

## 🎯 What This Project Does

| 🧩 Area | ✨ Functionality |
|---|---|
| 🧾 Sales Management | Add, update, delete and view sales |
| 💰 Revenue Analysis | Calculate and summarize total sales |
| 📦 Product Analysis | Compare products and quantities sold |
| 🏪 Category Analysis | Analyze sales across categories |
| 📈 Trend Analysis | Explore sales over time |
| 🔗 Correlation Analysis | Study relationships between numeric variables |
| 📊 Visualization | Create charts, plots and heatmaps |
| 💾 Data Storage | Read and update retail sales CSV data |

## 🗃️ Dataset

The project uses:

```text
retail_sales.csv
```

### 📌 Main Fields

| Column | Meaning |
|---|---|
| `Sale_ID` | Unique identifier for a sale |
| `Date` | Transaction date |
| `Category` | Product category |
| `Product` | Product name |
| `Quantity` | Number of units sold |
| `Unit_Price` | Price per unit |
| `Total_Sales` | Total transaction value |

### 💵 Revenue Calculation

```python
Total_Sales = Quantity × Unit_Price
```

## 🏪 Retail Sales Management

The project includes a `RetailStore` class to manage sales records.

### Available Operations

```text
➕ ADD
   Add a new retail transaction

🔄 UPDATE
   Modify quantity and unit price

❌ DELETE
   Remove an existing transaction

👀 VIEW
   Display sales records

📊 REPORT
   Generate sales and revenue summaries
```

Changes can be saved back to the CSV dataset.

## 📊 Data Analysis

The notebook performs several analysis tasks.

### 🔍 Exploratory Analysis

- Preview the dataset
- Inspect data structure
- Generate descriptive statistics
- Analyze numerical variables
- Calculate relationships between variables

### 💰 Product Revenue

A bar chart is used to compare total sales generated by products.

### 🏪 Category Performance

A pie chart shows the contribution of different categories to overall sales.

### 📦 Product Quantity

Product-level quantities are compared to identify higher-volume products.

### 📅 Sales Trend

A line chart is used to examine total sales across dates.

### 🔗 Correlation Analysis

The project explores relationships between:

- Unit price
- Quantity
- Total sales

A correlation matrix and heatmap provide an easy-to-read visual summary.
