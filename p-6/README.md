# 📖 My Personal Diary

A simple **Python Console-Based Personal Diary Application** that allows users to save, read, search, and delete diary entries. This project is beginner-friendly and demonstrates the use of **Python File Handling**, **Classes & Objects**, **Exception Handling**, **Loops**, **Match Case**, and **Date & Time Module**. The application stores all diary entries in a text file (`diary.txt`) along with the current date and time.

---

# 📌 Project Information

- **Project Name:** My Personal Diary
- **Language:** Python
- **Database:** Text File (`diary.txt`)
- **Python Version:** Python 3.10+
- **Project Type:** Console Based Application

---

# ✨ Features

✅ Write unlimited diary entries

✅ Automatically saves current Date & Time

✅ View all saved diary entries

✅ Search diary entries using any keyword

✅ Delete all diary entries

# 📝 Feature Explanation

## 1️⃣ Write New Entry

- User writes a diary entry.
- Current date and time are automatically added.
- Entry is stored inside `diary.txt`.

Example:

```
Write your diary entry :

Today I learned Python File Handling.
```

Saved as

```
2026-07-20 12:12:24

Today I learned Python File Handling.
```

---

## 2️⃣ Show All Entries

Displays every diary entry stored in the diary file.

Example

```
All Diary Entries

2026-07-20 12:12:24

Today I learned Python.

2026-07-21 09:30:10

Python is very interesting.
```

---

## 3️⃣ Find Entry

Searches diary entries using a keyword.

Example

```
Enter word to find :

Python
```

Output

```
Today I learned Python.
```

---

## 4️⃣ Remove All Entries

Deletes all diary entries after user confirmation.

```
Do you want to delete all entries?

yes
```

Output

```
All diary entries deleted.
```

---

## 5️⃣ Exit

Safely closes the application.

---

# 📄 How Data is Stored
